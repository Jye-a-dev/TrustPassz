🎨 Hướng Dẫn Copy / Import Chuẩn 1:1 Vào Figma

1. Builder.io Plugin

Mở file HTML bất kỳ trong trình duyệt, click chuột phải chọn "Copy Page" hoặc paste URL localhost vào plugin Builder.io trên Figma.

2. html.to.design

Nhập địa chỉ Live Server (vd: http://localhost:5500/...) trực tiếp vào plugin html.to.design, chọn khung Viewport 393px.

3. Vector & Auto Layout

Tất cả icon đã được chuẩn hóa thành Inline SVG nên khi import sẽ tự động nhận diện thành Vector Layer và Frame linh hoạt.

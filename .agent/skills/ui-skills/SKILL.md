# UI-Skills Directive (TrustPassz)

- Giao diện: Cyber-Escrow Dark Theme (Nền Slate-950 `#0B0F17`, viền zinc-800, Card `#0F172A`).
- Highlight: Emerald (#10B981) và Cyan (#06B6D4).
- Touch Target: Mọi nút bấm, input, thumb slider trên giao diện di động bắt buộc >= 44px (touch-action: manipulation).
- Bố cục: Mobile-First, chống tràn ngang (overflow-x-hidden), zero layout shift.
